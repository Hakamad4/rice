# Logos dos provedores de IA

Ícones do pacote [`simple-icons`](https://simpleicons.org) (licença **CC0 1.0**, domínio público). Copiados uma vez com `npm pack`; o Rice não depende do pacote em runtime.

| Arquivo | Origem | Cor oficial (hex) |
|---|---|---|
| `claude.svg` | simple-icons 16.34.0 (`claude`) | `#D97757` |
| `googlegemini.svg` | simple-icons 16.34.0 (`googlegemini`) | `#8E75B2` |
| `openai.svg` | simple-icons 14.0.0 (`openai`) — o ícone foi removido das versões mais novas do pacote | `#412991` |

| `opencode.svg` | desenhado para o Rice: quadrado de cantos retos com “OC” geométrico (não é o logo oficial) | `#3B3B3B` |

As marcas pertencem aos respectivos donos. Aqui os logos servem **só para identificar o provedor** escolhido na tela de conexão e no indicador “via …”; não são o ícone do Rice.

Uso na interface: `mask-image` + `background-color` (cor da marca, clareada no tema escuro quando precisa), por isso os SVGs não têm cor própria.
