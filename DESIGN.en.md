# Rice design (summary)

**The app uses `design/tokens.css`** (imported by `index.html`, `alert.html`, `nub.html`); `tests/design/tokens.test.ts` fails on any literal hex/rgb color outside it (provider logos excepted). Full guide in Portuguese: [DESIGN.md](DESIGN.md).

- `design/tokens.css` / `design/tokens.json`: same values, generated by `node design/build-tokens.mjs`.
- `design/divergencias.md`: near-duplicate values that should become one, with locations and suggestions (Portuguese).
- Source of truth today: the `<style>` of `src/renderer/index.html`, `alert.html`, `nub.html`.

**Principles.** Local-first and no personal data in the UI or sample content. Light on weight and motion. No emoji; line icons only (1.5 stroke on a 24 grid, `currentColor`). Every visible string goes through `t()` (pt-BR and en together). Responsive down to a 420 px window and at 1.44 zoom (about 820 CSS px), no horizontal scroll. Light and dark follow the system. Emphasis comes from weight and contrast; the accent is for focus and selection, red only for errors and recording.

**Tokens (summary).** Semantic colors: `--bg`, `--sidebar`, `--ink`, `--muted`, `--faint`, `--hover`, `--active`, `--field-bg`, `--line`, `--accent`, `--ring`, `--ok`, `--warn`, `--danger`, `--rec`. Type: system sans, sizes 11/12/13/14/15/16/20, weights 400/500/600, line heights 1.3/1.4/1.5/1.6. Spacing: a single `--space-*` scale (the old `--gap-*` was merged into it). Radii 4/6/8/10/12/14/pill. Motion 120/180/300 ms. Control heights 24/28/32/36. Window breakpoints 1000/760/560.

**Components** (buttons, switches, fields, cards, tabs, segmented control, chips, menus, dialogs, toasts, the mini panel `nub.html`, the meeting alert `alert.html`) and where each lives in the code are listed in the Portuguese guide.

**Voice.** Direct, calm, short sentences. No exclamation marks. Say what happened and what to do next; never blame the user. Action verbs on buttons; an ellipsis only for work in progress ("Generating ideas…"). Use they/them when someone's pronouns are unknown.
